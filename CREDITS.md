## Logotipo

El logotipo de **Renova Express** es propiedad de Renova Express Psicotécnicos S.L. y NO se ha recreado en esta web. En la implementación actual aparece como placeholder (`RE` sobre fondo verde) hasta que el cliente suba el archivo SVG/PNG original a `assets/img/logo-renovaexpress.svg`.

## Mapas

Los mapas incrustados son embeds gratuitos de **Google Maps** y no requieren API key para uso embebido.
